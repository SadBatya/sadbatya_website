# SadBatya Website

Личный веб-сайт и портфолио SadBatya, разработанный с использованием современных веб-технологий.

## 🚀 Технологии

- **Frontend**: React 19 + NextJS + TypeScript
- **Стилизация**: Tailwind CSS
- **Маршрутизация**: App router
- **Пакетный менеджер**: npm
- **Тесты**: Playwright
- **CI/CD**: Vercel

## 📦 Установка и запуск
npm i && npm run dev on localhost:3000

### Предварительные требования
- Node.js (версия 18 или выше)
- npm (рекомендуется) или yarn
